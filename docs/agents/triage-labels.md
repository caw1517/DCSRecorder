# Triage labels

Use these exact GitHub label names:

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | needs-triage | Maintainer evaluation needed |
| Needs information | needs-info | Waiting for reporter information |
| Agent ready | ready-for-agent | Fully specified for autonomous implementation |
| Human ready | ready-for-human | Requires human implementation |
| Will not implement | wontfix | Will not be actioned |
