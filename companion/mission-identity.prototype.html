What the decision must acknowledge

  • The companion owns persistent aircraft associations and immutable mission revisions. A mission filename, list position, aircraft count, callsign, name or numeric editor ID is insufficient by itself.
  • Selected-aircraft configuration and authored placement must remain compatible. The first recorded pose is separate and never moves when the scene changes.
  • A future trusted load check could compare the generated archive against an external preparation record. That needs live validation. The existing recording fingerprint checks the tape, not the mission.
  • Later script actions, editor test flights from temporary data, a missing checker, and changes after verification need explicit coverage decisions. This demo makes no universal detection claim.
  • Legacy takes keep their existing playback path. Selecting a scene now cannot create missing historical provenance.
